二叉树主要有两种遍历方式：

  • 深度优先遍历：先往深走，遇到叶子节点再往回走。
  • 广度优先遍历：一层一层的去遍历。

那么从深度优先遍历和广度优先遍历进一步拓展，才有如下遍历方式：

  • 深度优先遍历
    • 前序遍历（递归法，迭代法）
    • 中序遍历（递归法，迭代法）
    • 后序遍历（递归法，迭代法）
  • 广度优先遍历
    • 层次遍历（迭代法）

深度优先遍历的三种方式的顺序是：

  • 前序遍历：根左右
  • 中序遍历：左根右
  • 后序遍历：左右根

深度优先遍历就像是绕着整棵二叉树的外围“走”一圈，在每个节点都会遇到三个位置，分别对应前序遍历、中序遍历和后序遍历。

其实“中序遍历是先访问左子树，再访问根节点，再访问右子树”。这么描述是不准确的，容易产生误导。

事实上，无论是前、中、后序遍历，都是先访问根节点，再访问它的左子树，再访问它的右子树。

那它们之间的区别在哪里？

这也要看递归的本质了。

  • “递”（递推）：函数不断调用自己，往树的深处走（从父节点走向子节点）。

  • “归”（回溯）：当遇到 None（空节点）或子节点全部处理完时，函数返回到上一层调用它的地方，继续执行下一行代码。这个“返回到上一层”的动作，就是“回溯”。

就拿深度优先遍历的几种顺序来讲：

  • 前序遍历：刚进入节点就打印了，回溯时，节点已经打印过了。
  • 中序遍历：左子树递推结束，回溯到当前节点时才打印
  • 后序遍历：右子树递推结束，回溯到当前节点时才打印

一句话总结递归遍历的本质：每个节点都会被“经过三次机会”：进入时 / 左子树返回后 / 右子树返回后，在哪一步写代码，就决定是哪种遍历。

为了更好的理解这三种顺序，举例一棵树：

    1
   / \
  2   3
 / \   \
4   5   6
   /
  7

前序遍历：1 2 4 5 7 3 6 中序遍历：4 2 7 5 1 3 6 后序遍历：4 7 5 2 6 3 1

递归遍历

递归算法的三个要素。每次写递归，都按照这三要素来写:

  1. 确定参数和返回值

    • 如何确定参数？
      • 哪些状态需要在这条递归链条上一直传递，比如前序遍历中，那个用来装结果的 vector& vec 就是需要贯穿始终的，所以必须作为参数传进去。
    • 如何确定返回值？
      • 执行动作（无返回值）： 如果你的任务是“去把这件事办了”（比如：把节点值全塞进数组里），那返回值通常是 void。因为不需要它告诉你结果，只需要它执行动作。
      • 索要结果（有返回值）： 如果你的任务是“去帮我查个数据”（比如：这棵树的最大深度是多少？这两个节点是不是对称的？），那返回值必须是对应的类型（int, bool 等）。

  2. 确定终止条件

    • 在二叉树里，最极端的情况往往就是“走到头了”，也就是遇到了空节点（null）。
    • 结合第一步的返回值来定。如果是 void，直接 return;；如果是求深度，空节点深度就是 0，写 return 0;；如果是判断是否对称，空节点也算对称，写 return true;

  3. 确定单层递归的逻辑

    • 只管好你自己（当前节点），剩下的事当甩手掌柜交给小弟（子节点）去办。
    • 绝对不要去想小弟是怎么完成任务的（不要在脑海里进下一层递归），你要无条件信任你刚才定义的这个黑盒函数，相信它一定能完美处理子节点。
    • 怎么写单层逻辑？
      • 假设你就是当前正在被处理的这个节点（root）
      • 现在有三个要素：你自己的值（root.val），你的左小弟（root.left），你的右小弟（root.right）。
      • 分配任务： 把左小弟扔进黑盒 递归函数(root.left)，把右小弟扔进黑盒 递归函数(root.right)。
      • 组合结果： 思考“我自己的值”和“左小弟传回来的结果”、“右小弟传回来的结果”之间，要怎么排列组合，才能得出当前这层需要的结果？（比如：前序遍历就是先处理我自己的值，再管左右小弟）。

func preorderTraversal(root *TreeNode) (res []int) {
    var traversal func(node *TreeNode)
    traversal = func(node *TreeNode) {
        if node == nil {
                return
        }
        res = append(res,node.Val)
        traversal(node.Left)
        traversal(node.Right)
    }
    traversal(root)
    return res
}

求二叉树的最大深度

  1. 确定参数和返回值
  • 返回值：既然是求“深度”，那结果必然是一个整数，所以返回值类型是 int。
  • 参数：我要算谁的深度？当然是给我哪棵树，我就算哪棵树。

  1. 确定终止条件 如果传进来的节点是空的（root == nullptr），那深度就是 0。

  2. 确定单层递归的逻辑

  • 我是当前节点 node。我的最大深度怎么算？
  • 问左小弟：你那边的最大深度是多少？
  • 问右小弟：你那边的最大深度是多少？
  • 组合：左右子树的最大深度加上自己这一层就是最大深度啊

func maxDepth(node *TreeNode)int{
    if node == nil{return 0}
    left_depth := maxDepth(node.Left)
    right_depth := maxDepth(node.Right)
    return max(left_depth,right_depth)+1
}

type Node struct {
    treenode *TreeNode
    handled int
} 

func inorderTraversal(root *TreeNode) []int {
    res := make([]int,0)
    stack := make([]Node,0)
    stack = append(stack,Node{root,0})
    for len(stack) > 0{
        // 出栈
        node := stack[len(stack)-1]
        stack = stack[:len(stack)-1]
        
        if node.treenode == nil{
            // 递归的终止条件
            continue
        }
        if node.handled == 0{
            // 当前节点还没开始处理，进行递推
            stack = append(stack,Node{node.treenode.Right,0})
            stack = append(stack,Node{node.treenode,1})
            stack = append(stack,Node{node.treenode.Left,0})
        }
        if node.handled == 1{
            // 归的过程
            res = append(res,node.treenode.Val)
        }
    }

    return res
}

func preorderTraversal(root *TreeNode) []int {
    res := make([]int,0)
    stack := make([]Node,0)
    stack = append(stack,Node{root,0})
    for len(stack) > 0{
        // 出栈
        node := stack[len(stack)-1]
        stack = stack[:len(stack)-1]
        
        if node.treenode == nil{
            // 递归的终止条件
            continue
        }
        if node.handled == 0{
            // 当前节点还没开始处理，进行递推
            stack = append(stack,Node{node.treenode.Right,0})
            stack = append(stack,Node{node.treenode.Left,0})
            stack = append(stack,Node{node.treenode,1})
        }
        if node.handled == 1{
            // 归的过程
            res = append(res,node.treenode.Val)
        }
    }

    return res
}

func postorderTraversal(root *TreeNode) []int {
    res := make([]int,0)
    stack := make([]Node,0)
    stack = append(stack,Node{root,0})
    for len(stack) > 0{
        // 出栈
        node := stack[len(stack)-1]
        stack = stack[:len(stack)-1]
        
        if node.treenode == nil{
            // 递归的终止条件
            continue
        }
        if node.handled == 0{
            // 当前节点还没开始处理，进行递推
            stack = append(stack,Node{node.treenode,1})
            stack = append(stack,Node{node.treenode.Right,0})
            stack = append(stack,Node{node.treenode.Left,0})
        }
        if node.handled == 1{
            // 归的过程
            res = append(res,node.treenode.Val)
        }
    }

    return res
}

func levelOrder(root *TreeNode) (res [][]int) {
    if root == nil {
        return
    }

    curLevel := []*TreeNode{root}  // 存放当前层节点
    for len(curLevel) > 0 {
        nextLevel := []*TreeNode{}  // 准备通过当前层生成下一层
        vals := []int{}

        for _, node := range curLevel {
            vals = append(vals, node.Val) // 收集当前层的值
            // 收集下一层的节点
            if node.Left != nil {
                nextLevel = append(nextLevel, node.Left)
            }
            if node.Right != nil {
                nextLevel = append(nextLevel, node.Right)
            }
        }
        res = append(res, vals)
        curLevel = nextLevel // 将下一层变成当前层
    }

    return
}

func levelOrder(root *TreeNode) [][]int {
     res := make([][]int, 0)
     if root == nil {
        return res
     }
     queue := make([]*TreeNode, 0)
     queue = append(queue, root)
     for len(queue) > 0 {
          size := len(queue)
          level := make([]int, 0)
          for i := 0; i < size; i++ {
               node := queue[0]
               queue = queue[1:]
               level = append(level, node.Val)
               if node.Left != nil {
				   queue = append(queue, node.Left)
               }
               if node.Right != nil {
				   queue = append(queue, node.Right)
               }
          }
          res = append(res, level)
     }
     return res
}
