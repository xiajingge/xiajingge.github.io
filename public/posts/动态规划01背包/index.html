这一节主要讲的是关于01背包问题的集合。

二维dp理论基础

假设现在有这样的一个问题：有一个重量容量为4的背包，可以装以下的物品，问背包能背的物品的最大价值是多少？

重量价值
物品0115
物品1320
物品2430

那现在先给出一个dp二维数组，主要是两个维度：物品和背包重量

可以看出二维输出的行是物品种类，列是背包容量。

那现代来填一下这个数组的内容。

  • 先看第一行：

    在仅考虑物品0的情况下，主要背包容量大于物品0的重量，那最大的价值就是物品0

  • 再看第二行

    • 同时考虑物品0和物品1时。

    • 当背包容量不够装下物品1（重量是3）时，只能装物品0

    • 当背包容量可以装下物品1时，那肯定是先装物品1，因为价值很高

其实填到这里，基本就是dp[i][j]的含义了。即dp[i][j] 表示从下标为[0-i]的物品里任意取，放进容量为j的背包，价值总和最大是多少。

那有了dp数组，就要开始推dp递推公式了

那就是我们要推出dp[i][j],这里我们拿dp[1][4]举例。

求dp[1][4]就是两种情况：

  • 放物品1
  • 不放物品1

那先看不放物品1的情况，那就是只放物品0。就是dp[0][4]的值

那如果放物品1的情况，那就是提前预留出放物品1的容量空间，本例中物品1的重量是3，那就是需要在预留出3这个空间，就是dp[0][1]

两种情况，分别是放物品1 和 不放物品1，我们要取最大值（毕竟求的是最大价值）

dp[1][4] = max(dp[0][4], dp[0][1] + 物品1 的价值)

以上过程，抽象化如下：

不放物品i：背包容量为j，里面不放物品i的最大价值是dp[i - 1][j]。

放物品i：背包空出物品i的容量后，背包容量为j - weight[i]，dp[i - 1][j - weight[i]] 为背包容量为j - weight[i]且不放物品i的最大价值，那么dp[i - 1][j - weight[i]] + value[i] （物品i的价值），就是背包放物品i得到的最大价值

递归公式： dp[i][j] = max(dp[i - 1][j], dp[i - 1][j - weight[i]] + value[i]);

dp数组如何初始化

可以看出是从左到右、从上到下的顺序，那第一行和第一列就是需要初始化。

  • 第一行：即只有物品0的情况，那就是当容量大于等于物品0重量时，初始化为物品0的价值
  • 第一列：即背包容量是0，那就是放不下任何的物品，价值是0

一维dp理论基础

其实一维的思想与二维完全一致，所以必须先看懂二维dp理论基础。

主要从二维数组的初始化部分。

可以看出第二行的数据是由第一行的部分数据计算得到的，那这说明什么，说明我们只需要一行的数据空间就可以实现二维的效果，这也是滚动数组的含义。

那dp该怎么定义呢，就是去掉i这个维度就可以了，即dp[j]，dp[j] = max(dp[j], dp[j - weight[i]] + value[i]);

那dp该怎么初始化呢？可以看图，一个数据是通过正上方的数据和左方（其实是左上方，但是滚动起来就是左方的感觉）的数据得到的。

那最终使用的是max得到的最终结果，那就需要初始化一个不被max影响的数，其实就是非负数的最小值，就是0了。

那dp该怎么遍历呢？其实这就是与二维数组有一点区别了，先看结果。

for(int i = 0; i < weight.size(); i++) { // 遍历物品
    for(int j = bagWeight; j >= weight[i]; j--) { // 遍历背包容量
        dp[j] = max(dp[j], dp[j - weight[i]] + value[i]);
    }
}

区别就在于背包容量的遍历方向上，这就需要我们对滚动数组有一个清晰的数值覆盖的画面。

我们提到了看图：一个数据是通过正上方的数据和左方（其实是左上方，但是滚动起来就是左方的感觉）的数据得到的。

那说明一个数据是依靠左边的原始数据的，所以需要先计算右边的，这样左边的数据不会被覆盖掉。

1. 分割等和子集

题目描述

  1. 给定一个只包含正整数的非空数组。是否可以将这个数组分割成两个子集，使得两个子集的元素和相等。

注意: 每个数组中的元素不会超过 100 数组的大小不会超过 200

思路

分割成两个等和子集 -> 找到一个子集的和是全部数组和的一半 -> 在数组和一半这个容量下，在数组中找出几个数据，然后装满这个背包 -> 01背包问题

  1. 确定dp数组

dp[j]:容量为j的背包能装的最大容量是dp[j] 在本题中就是dp[sum/2] ?= sum/2 -> 也就是看是否能装满这个背包

  1. 确定递推公式

dp[j] = max(dp[j],dp[i-1][j-nums[i]]+num[i]) 因为对于数组而言，物品的重量是nums[i]，价值也是nums[i]

  1. dp数组初始化

for i := range length(nums)+1 { dp[i] = 0 }

  1. 确定遍历顺序

func canPartition(nums []int) bool {
	n := len(nums)
	sum := 0
	for _, num := range nums {
		sum += num
	}
	if sum%2 == 1 {
		return false
	}
	target := sum / 2
	dp := make([]int, target+1)

	for i := 0; i < n; i++ {
		for j := target; j >= 0; j-- {
			if j >= nums[i] {
				dp[j] = max(dp[j], dp[j-nums[i]]+nums[i])
			}
		}
	}

	if dp[target] == target {
		return true
	}
	return false
}

func canPartition(nums []int) bool {
	n := len(nums)
	sum := 0
	for _, num := range nums {
		sum += num
	}
	if sum%2 == 1 {
		return false
	}
	target := sum / 2
	dp := make([]int, target+1)

	for i := 0; i < n; i++ {
        // 因为滚动数据覆盖，所以不需要全部遍历
		for j := target; j >= nums[i]; j-- {
			dp[j] = max(dp[j], dp[j-nums[i]]+nums[i])
		}
	}

	if dp[target] == target {
		return true
	}
	return false
}

2. 最后一块石头的重量II

题目描述

  1. 有一堆石头，每块石头的重量都是正整数。

每一回合，从中选出任意两块石头，然后将它们一起粉碎。假设石头的重量分别为 x 和 y，且 x <= y。那么粉碎的可能结果如下：

如果 x == y，那么两块石头都会被完全粉碎；

如果 x != y，那么重量为 x 的石头将会完全粉碎，而重量为 y 的石头新重量为 y-x。

最后，最多只会剩下一块石头。返回此石头最小的可能重量。如果没有石头剩下，就返回 0。

思路

这个题目和上一个题目分割等和子集的思路是基本类似的.

将一堆石头看成是数组，每一个石头就是数据，因为两个石头比较粉碎后是会剩下一个新的石头的，然后会参与后续的比较。

那其实就是将数组分割成了两个数组，然后将和进行相减，就是最小重量。

  • 两堆总重量分别为 sumA 和 sumB，且 sumA + sumB = total。

  • 假设 sumA ≤ sumB，则最后剩余石头重量 = sumB - sumA。

为了最小化这个差值，应让两堆总重量尽可能接近，即让 sumA 尽可能接近 total/2

  1. 确定dp数组

dp[j]：容量为j的背包能容纳的最大价值是dp[j] 2. 确定递推公式

01背包问题：dp[j] = max(dp[j],dp[j-weight[i]]+value[i]) 本题目的最大容量j是sum/2

  1. dp数组初始化

  1. 确定遍历顺序

func lastStoneWeightII(stones []int) int {
	sum := 0
	n := len(stones)
	for _, v := range stones {
		sum += v
	}
	target := sum / 2
	dp := make([]int, target+1)

	for i := 0; i < n; i++ {
		for j := target; j >= stones[i]; j-- {
			dp[j] = max(dp[j], dp[j-stones[i]]+stones[i])
		}
	}

	return sum - 2*dp[target]
}

3. 目标和

题目描述

  1. 给定一个非负整数数组，a1, a2, …, an, 和一个目标数，S。现在你有两个符号 + 和 -。对于数组中的任意一个整数，你都可以从 + 或 -中选择一个符号添加在前面。

返回可以使最终数组和为目标数 S 的所有添加符号的方法数。

思路

其实这个题目还是和分割等和子集一个思路，只是绕了一下。

给定两个符号 + 和 - ，其实就是分成了两个子集，那么假设是

nums: [a, b, c, q, w, e] A: [a, b, c] B: [q, w, e]

那就是A全是+，B全是-，其实sumA - sumB = s

sumA + sumB = total,

这样其实sumA = (total + s) / 2

这就是01背包问题：能不能装满sumA这个容量的背包

  1. 确定dp数组

dp[j]:装满容量为j的背包有几种方法

  1. 确定递推公式

当我们处理一个新的元素nums[i]时，有两种选择：

  • 不选它：那dp[j] = 之前算出的dp[j]
  • 选它：那先将nums[i]的空间腾出来，就是dp[j-nums[i]]，此时方法数就是dp[j-nums[i]]的方法数

那总的方法数就是 dp[j] = dp[j] + dp[j-nums[i]]

  1. dp数组初始化

j是需要依赖j-nums[i]的，那么对于01背包就是倒序遍历

  1. 确定遍历顺序

01背包问题

求组合类的问题就是dp[j] += dp[j - nums[i]]

func findTargetSumWays(nums []int, target int) int {
	sum := 0
	n := len(nums)
	for _, v := range nums {
		sum += v
	}

    // 防止target > sum 或者 target的负数也大于sum
	if abs(target) > sum {
		return 0
	}
	if (sum+target)%2 == 1 {
		return 0
	}
	t := (sum + target) / 2

	dp := make([]int, t+1)
	dp[0] = 1
	for i := 0; i < n; i++ {
		for j := t; j >= nums[i]; j-- {
			dp[j] += dp[j-nums[i]]
		}
	}
	return dp[t]
}

func abs(x int) int {
	if x >= 0 {
		return x
	}
	return -x
}

4. 一和零

题目描述

  1. 给你一个二进制字符串数组 strs 和两个整数 m 和 n 。

请你找出并返回 strs 的最大子集的大小，该子集中 最多 有 m 个 0 和 n 个 1 。

如果 x 的所有元素也是 y 的元素，集合 x 是集合 y 的 子集 。

思路

其实就是将m和n看作是背包的容量，上述的背包容量只有一个维度就是重量，但是本题的背包容量是有两个维度m和n

整体转换成背包问题局势装满容量为m和n的背包的最大子集的大小是多少

  1. 确定dp数组

dp[i][j]:装满i个0和j个1的背包最多装dp[i][j]个物品

  1. 确定递推公式

dp[i][j] 可以由前一个strs里的字符串推导出来，strs里的字符串有 x 个0，y 个1。

dp[i][j] 就可以是 dp[i - x][j - y] + 1。

然后我们在遍历的过程中，取dp[i][j]的最大值。

所以递推公式就是dp[i][j] = max(dp[i][j],dp[i-x][j-y]+1)

这就是一个典型的01背包！

  1. dp数组初始化

在01背包基础部分已经讲解了，01背包的dp数组初始化为0就可以。

因为物品价值不会是负数，初始为0，保证递推的时候dp[i][j]不会被初始值覆盖。

  1. 确定遍历顺序

我们讲到了01背包为什么一定是外层for循环遍历物品，内层for循环遍历背包容量且从后向前遍历！

那么本题也是，物品就是strs里的字符串，背包容量就是题目描述中的m和n。

func findMaxForm(strs []string, m int, n int) int {
	dp := make([][]int, m+1)
	for i, _ := range dp {
		dp[i] = make([]int, n+1)
	}

	// 遍历物品
	for i := 0; i < len(strs); i++ {
		x, y := 0, 0
		for _, v := range strs[i] {
			if v == '0' {
				x++
			}
			if v == '1' {
				y++
			}
		}

		// 遍历背包容量
		for j := m; j >= x; j-- {
			for k := n; k >= y; k-- {
				dp[j][k] = max(dp[j][k], dp[j-x][k-y]+1)
			}
		}
	}
	return dp[m][n]
}

总结

本文主要是讲了0-1背包的基础理论和0-1背包的多种应用。

理论： 纯0-1背包是求 给定背包容量 装满背包 的最大价值是多少。

应用：

  1. 分割等和子集是求 给定背包容量，能不能装满这个背包。
  2. 最后一块石头的重量 II是求 给定背包容量，尽可能装，最多能装多少,这个就是基础理论
  3. 目标和是求 给定背包容量，装满背包有多少种方法。
  4. 一和零是求 给定背包容量，装满背包最多有多少个物品。
