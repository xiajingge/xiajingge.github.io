1. 零钱兑换2

题目描述

给定不同面额的硬币和一个总金额。写出函数来计算可以凑成总金额的硬币组合数。假设每一种面额的硬币有无限个。

思路

本题和纯完全背包不一样，纯完全背包是凑成背包最大价值是多少，而本题是要求凑成总金额的物品组合个数！

注意题目描述中是凑成总金额的硬币组合数，为什么强调是组合数呢？

例如示例一：

5 = 2 + 2 + 1

5 = 2 + 1 + 2

这是一种组合，都是 2 2 1。

如果问的是排列数，那么上面就是两种排列了。

组合不强调元素之间的顺序，排列强调元素之间的顺序。

  1. 确定dp数组

dp[i][j]:使用0到i-1的硬币凑成总金额j的组合数，其实就是装满j这个背包

  1. 确定递推公式

dp[i][j] = dp[i - 1][j] + dp[i][j - nums[i]]

  1. dp数组初始化

那么二维数组的最上行 和 最左列一定要初始化，这是递推公式推导的基础，如图颜色部分：

这里首先要关注的就是 dp[0][0] 应该是多少？

背包空间为0，装满「物品0」 的组合数有多少呢？应该是 0 个， 但如果 「物品0」 的 数值就是0呢？ 岂不是可以有无限个0 组合 和为0！

题目描述中说了1 <= coins.length <= 300 ，所以不用考虑 物品数值为0的情况。

那么最上行dp[0][j] 如何初始化呢？

如果 j 可以整除 物品0，那么装满背包就有1种组合方法。

最左列如何初始化呢？

dp[i][0] 的含义：用物品i（即coins[i]） 装满容量为0的背包 有几种组合方法。

都有一种方法，即不装。

所以 dp[i][0] 都初始化为1

  1. 确定遍历顺序

完全背包的遍历顺序

func change(amount int, coins []int) int {
	n := len(coins)
	dp := make([][]int, n)

	for i, _ := range dp {
		dp[i] = make([]int, amount+1)
	}

	for i := 0; i < n; i++ {
		dp[i][0] = 1
	}

	for j := 1; j <= amount; j++ {
		if j%coins[0] == 0 {
			dp[0][j] = 1
		}
	}

	for i := 1; i < n; i++ {
		for j := 1; j <= amount; j++ {
			if j < coins[i] {
				dp[i][j] = dp[i-1][j]
			} else {
				dp[i][j] = dp[i-1][j] + dp[i][j-coins[i]]
			}
		}
	}

	return dp[n-1][amount]
}

其实这个题目也是可以做成一维来进行解释的。

dp[j]:凑成金额为j的组合数是dp[j]

那想如果是凑成j=6，同时金额是[1,2,5]

在金额是1时，需要dp[5]种组合就可以凑成5

在金额是2时，需要dp[4]种组合就可以凑成5

在金额是5时，需要dp[1]种组合就可以凑成5

那其实就是dp[j] += dp[j-coins[i]]

那该怎么初始化呢，可以看到dp[j]是由之前的数字计算出来的，那dp[0]必然是需要初始化的，那初始化为多少呢？

  • 根据题意来讲，dp[0]是指凑出金额为0的组合数有哪些，那就是一个不选，就是1，但这种思考也容易理解成根本就凑不出金额0，所以是0，所以这种方式见仁见智

  • 根据地推公式来讲，dp[j] = dp[j]+ dp[j-coins[i]],dp[j]是通过前面的累加得到的，那如果初始化为0，那就算怎么累加，也会一直是0，所以是初始化为1

那地推顺序呢？

本题要找的是组合数，说明了{1,5}和{5,1}是同一种组合

那假设是先遍历背包，再遍历物品

func change(amount int, coins []int) int {
	n := len(coins)
	dp := make([]int, amount+1)
	dp[0] = 1
	for i := 0; i < n; i++ {
		for j := 1; j <= amount; j++ {
			if j >= coins[i] {
				dp[j] += dp[j-coins[i]]
			}
		}
	}

	return dp[amount]
}

2. 零钱兑换

题目描述

  1. 给定不同面额的硬币 coins 和一个总金额 amount。编写一个函数来计算可以凑成总金额所需的最少的硬币个数。如果没有任何一种硬币组合能组成总金额，返回 -1。

思路

本题和零钱兑换2不一样，本题求的不是组合数，而是个数

  1. 确定dp数组

dp[j]:凑成金额j的最少硬币个数dp[j]

  1. 确定递推公式

凑足总额为j - coins[i]的最少个数为dp[j - coins[i]]，那么只需要加上一个钱币coins[i]即dp[j - coins[i]] + 1就是dp[j]

所以dp[j] 要取所有 dp[j - coins[i]] + 1 中最小的。

递推公式：dp[j] = min(dp[j - coins[i]] + 1, dp[j]);

  1. dp数组初始化
  • 理论层面：dp[0]是个数，那肯定是0
  • 公式层面：dp[j]是取j之前的最小值，那为了避免影响min的判断，肯定是初始化为最大，这样才不会影响最小
  1. 确定遍历顺序

本题求钱币最小个数，那么钱币有顺序和没有顺序都可以，都不影响钱币的最小个数。

所以本题并不强调集合是组合还是排列。

如果求组合数就是外层for循环遍历物品，内层for遍历背包。

如果求排列数就是外层for遍历背包，内层for循环遍历物品。

func coinChange(coins []int, amount int) int {
	n := len(coins)
	dp := make([]int, amount+1)

	for i, _ := range dp {
		if i == 0 {
			dp[i] = 0
		} else {
			dp[i] = math.MaxInt32
		}
	}

	for j := 1; j <= amount; j++ {
		for i := 0; i < n; i++ {
			if j >= coins[i] {
				dp[j] = min(dp[j], dp[j-coins[i]]+1)
			}
		}
	}
	if dp[amount] == math.MaxInt32 {
		return -1
	}
	return dp[amount]
}

3. 组合总和4

题目描述

给定一个由正整数组成且不存在重复数字的数组，找出和为给定目标正整数的组合的个数。

示例:

nums = [1, 2, 3] target = 4 所有可能的组合为： (1, 1, 1, 1) (1, 1, 2) (1, 2, 1) (1, 3) (2, 1, 1) (2, 2) (3, 1)

请注意，顺序不同的序列被视作不同的组合。

因此输出为 7

思路

本题题目描述说是求组合，但又说是可以元素相同顺序不同的组合算两个组合，其实就是求排列！

那就与零钱兑换2中的遍历顺序不同，其他的都是一个思路

  1. 确定dp数组

dp[j]:成目标正整数为j的排列个数为dp[j]

  1. 确定递推公式

递推公式：dp[j] += dp[j - nums[i]]

  1. dp数组初始化

  • 题意层面，dp[0]是指凑出金额为0的排列数有哪些，那就是一个不选，就是1，但这种思考也容易理解成根本就凑不出金额0，所以是0，所以这种方式见仁见智

  • 公式层面：dp[j] = dp[j]+ dp[j-nums[i]],dp[j]是通过前面的累加得到的，那如果初始化为0，那就算怎么累加，也会一直是0，所以是初始化为1

  1. 确定遍历顺序

如果求排列数就是外层for遍历背包，内层for循环遍历物品。

func combinationSum4(nums []int, target int) int {
	n := len(nums)
	dp := make([]int, target+1)

	dp[0] = 1

	for j := 1; j <= target; j++ {
		for i := 0; i < n; i++ {
			if j >= nums[i] {
				dp[j] += dp[j-nums[i]]
			}
		}
	}
	return dp[target]
}

4. 完全平方数

题目描述

  1. 给定正整数 n，找到若干个完全平方数（比如 1, 4, 9, 16, …）使得它们的和等于 n。你需要让组成和的完全平方数的个数最少。

给你一个整数 n ，返回和为 n 的完全平方数的 最少数量 。

完全平方数 是一个整数，其值等于另一个整数的平方；换句话说，其值等于一个整数自乘的积。例如，1、4、9 和 16 都是完全平方数，而 3 和 11 不是。

示例 ：

输入：n = 13 输出：2 解释：13 = 4 + 9

思路

完全平方数就是物品（可以无限件使用），凑个正整数n就是背包，问凑满这个背包最少有多少物品？

和零钱兑换是一样的。

  1. 确定dp数组

dp[j]:和为j的完全平方数的最少数量为dp[j]

  1. 确定递推公式

dp[j] 可以由dp[j - i * i]推出， dp[j - i * i] + 1 便可以凑成dp[j]。

所以dp[j] 要取所有 dp[j - i * i] + 1 中最小的。

递推公式：dp[j] = min(dp[j - i * i] + 1, dp[j]);

  1. dp数组初始化
  • 理论层面：dp[0]是个数，那肯定是0
  • 公式层面：dp[j]是取j之前的最小值，那为了避免影响min的判断，肯定是初始化为最大，这样才不会影响最小
  1. 确定遍历顺序

本题求最小个数，那么有顺序和没有顺序都可以，都不影响最小个数。

所以本题并不强调集合是组合还是排列。

如果求组合数就是外层for循环遍历物品，内层for遍历背包。

如果求排列数就是外层for遍历背包，内层for循环遍历物品。

func numSquares(n int) int {
	dp := make([]int, n+1)
	for i, _ := range dp {
		if i == 0 {
			continue
		} else {
			dp[i] = math.MaxInt32
		}
	}

	for i := 1; i*i <= n; i++ {
		for j := i * i; j <= n; j++ {
			dp[j] = min(dp[j], dp[j-i*i]+1)
		}
	}

	if dp[n] == math.MaxInt32 {
		return 0
	}
	return dp[n]
}

5. 单词拆分

题目描述

  1. 给定一个非空字符串 s 和一个包含非空单词的列表 wordDict，判定 s 是否可以被空格拆分为一个或多个在字典中出现的单词。

说明：

拆分时可以重复使用字典中的单词。

你可以假设字典中没有重复的单词。

示例 1：

输入: s = “leetcode”, wordDict = [“leet”, “code”] 输出: true 解释: 返回 true 因为 “leetcode” 可以被拆分成 “leet code”。

思路

单词就是物品，字符串s就是背包，单词能否组成字符串s，就是问物品能不能把背包装满。

拆分时可以重复使用字典中的单词，说明就是一个完全背包！

  1. 确定dp数组

dp[i] : 字符串长度为i的话，dp[i]为true，表示可以拆分为一个或多个在字典中出现的单词。

  1. 确定递推公式

dp[j] 可以由dp[j - i]推出，

  • 如果dp[j - i]是true，同时区间[i, j]里的字母在物品中能找到 - > dp[j]=true。

递推公式：dp[j] = dp[j-i] && [i,j]是否出现中字典;

  1. dp数组初始化
  • 公式层面：dp[j]是取j之前的值，那为了避免影响后续的与操作，那dp[0]一定是true，不然后续全是false了
  1. 确定遍历顺序

如果求组合数就是外层for循环遍历物品，内层for遍历背包。

如果求排列数就是外层for遍历背包，内层for循环遍历物品。

而本题其实我们求的是排列数，为什么呢。 拿 s = “applepenapple”, wordDict = [“apple”, “pen”] 举例。

“apple”, “pen” 是物品，那么我们要求 物品的组合一定是 “apple” + “pen” + “apple” 才能组成 “applepenapple”。

“apple” + “apple” + “pen” 或者 “pen” + “apple” + “apple” 是不可以的，那么我们就是强调物品之间顺序。

所以说，本题一定是 先遍历 背包，再遍历物品。

func wordBreak(s string, wordDict []string) bool {
	wordSet := make(map[string]bool)
	for _, v := range wordDict {
		wordSet[v] = true
	}

	dp := make(map[int]bool)

	dp[0] = true

    // 遍历背包
	for j := 1; j <= len(s); j++ {
		// 内层是遍历物品，而本题的物品是[i,j]这个区间的字符，所以是i<j
        for i := 0; i < j; i++ {
			if dp[i] && wordSet[s[i:j]] {
				dp[j] = true
			}
		}
	}
	return dp[len(s)]
}

总结

完全背包问题基本与01背包相同，只有一点不同，就是一维dp数组的遍历顺序

纯完全背包的一维dp数组实现，先遍历物品还是先遍历背包都是可以的，且第二层for循环是从小到大遍历。

如果求组合数就是外层for循环遍历物品，内层for遍历背包。

如果求排列数就是外层for遍历背包，内层for循环遍历物品。

如果求最小数，那么两层for循环的先后顺序就无所谓了
