1. 最长递增子序列

题目描述

  1. 给你一个整数数组 nums ，找到其中最长严格递增子序列的长度。

子序列是由数组派生而来的序列，删除（或不删除）数组中的元素而不改变其余元素的顺序。例如，[3,6,2,7] 是数组 [0,3,1,6,2,2,7] 的子序列。

示例 1：

输入：nums = [10,9,2,5,3,7,101,18] 输出：4 解释：最长递增子序列是 [2,3,7,101]，因此长度为 4 。

思考

  1. 如何确定动态规划

首先看见本题，让我们求最长递增子序列长度，那直观的想法就是：

dp[i]: nums[….i]里的最长自增子序列长度

如果这样定义，那我们看看当指针走到i时，能不能从前面的状态推导出来：

假设nums = [10, 9, 2, 5, 3, 7]

当i = 3时，也就是[10, 9, 2, 5]的最长递增子序列长度是2，dp[3] = 3

当i = 4时，也就是[10, 9, 2, 5, 3]，新加入一个3。

发现这个3不知道该和谁比较了，只知道dp[3] = 3，dp[4]没办法从dp[3]获取有用数据。

那重新思考，dp[4]该从dp[3]中获取什么？ 要求显而易见，就是必须能和nums[4]做比较。

但因为是不连续的，之前的任何数都可能是序列结尾，所以都要做判断。

所以得知道每一个子序列的尾数是是多少，然后+1就可以了。

那dp数组就出来了。

  1. 确定dp数组

dp[i]:以nums[i]为结尾的最长递增子序列的长度是dp[i]

以nums[i]为结尾，表示可以直接和nums[i]比较，然后+1即可。

2.确定递推公式

当求dp[6]时，只需要和nums[0]…nums[5]分别做比较，然后大于就dp[j] + 1

if nums[i] > nums[j] { dp[i] = max(dp[j] + 1,dp[i]) }

所有都比较完之后，会有6个dp[6],取最大值作为最终的dp[6]

3.dp数组初始化

i是从左向右，每次确定dp[i]都是将dp[i] 与 dp[j]+1做比较，所以每一个位置的dp[i]初始值是1，然后求的max

func lengthOfLIS(nums []int) int {
	n := len(nums)
	dp := make([]int, n)
	for i, _ := range dp {
		dp[i] = 1
	}

	res := 1

	for i := 1; i < n; i++ {
		for j := 0; j < i; j++ {
			if nums[i] > nums[j] {
				dp[i] = max(dp[j]+1, dp[i])
			}
		}
		if res < dp[i] {
			res = dp[i]
		}
	}

	return res
}

2. 最长连续递增序列

题目描述

  1. 给定一个未经排序的整数数组，找到最长且 连续递增的子序列，并返回该序列的长度。

连续递增的子序列 可以由两个下标 l 和 r（l < r）确定，如果对于每个 l <= i < r，都有 nums[i] < nums[i + 1] ，那么子序列 [nums[l], nums[l + 1], …, nums[r - 1], nums[r]] 就是连续递增子序列。

示例 1：

输入：nums = [1,3,5,4,7] 输出：3 解释：最长连续递增序列是 [1,3,5], 长度为3。尽管 [1,3,5,7] 也是升序的子序列, 但它不是连续的，因为 5 和 7 在原数组里被 4 隔开。

思路

这道题目与最长递增子序列的区别就在于连续。

在看这个题目之前先看最长递增子序列的思路部分，简短解释就是因为是连续子序列，所以dp[4]的比较值就是nums[3]，这是确定值了，所以不需要获取之前所有的dp求最大了

  1. 确定dp数组

dp[i]:以nums[i]为结尾的最长连续递增子序列的长度是dp[i]

2.确定递推公式

当求dp[6]时，只需要和nums[5]分别做比较，然后大于就dp[5] + 1

if nums[i] > nums[j]{ dp[i] = dp[i-1]+1 }

func findLengthOfLCIS(nums []int) int {
	n := len(nums)
	dp := make([]int, n)
	dp[0] = 1

	res := 1
	for i := 1; i < n; i++ {
		if nums[i] > nums[i-1] {
			dp[i] = dp[i-1] + 1
		} else {
			dp[i] = 1
		}

		if res < dp[i] {
			res = dp[i]
		}
	}
	return res
}

3. 最长重复子数组

题目描述

  1. 给两个整数数组 A 和 B ，返回两个数组中公共的、长度最长的子数组的长度。

示例：

输入：

A: [1,2,3,2,1] B: [3,2,1,4,7] 输出：3 解释：长度最长的公共子数组是 [3, 2, 1] 。

思路

首先看到这个题目很难想到动态规划，估计第一反应可能是暴力搜索，就是找了相同的起点，然后向后遍历对比。

可以看出暴力的解法的关注点是起点，而动态规划的关注点是终点。

那么换一种思考方式，假设两个数组：[0,1,2,3] [9,1,2,3]

当我们看到两个数组的结尾是3，那连续的序列不就是它俩的上一位的连续长度+1么。

而上述正好是结尾相同，但其实

  • $nums1$ 的每一个位置都可能作为公共子数组的结尾。
  • $nums2$ 的每一个位置也都可能作为公共子数组的结尾。

我们需要一格一格地去记录：当 $nums1$ 进行到第 $i$ 个位置，且 $nums2$ 进行到第 $j$ 个位置，并且这两个位置的数据正好相等时，他们俩往前看，到底能凑出多长的连续重复数组。

所以，dp[i][j] 的本源意义就是：为了记录 $nums1[i]$ 和 $nums2[j]$ 强行凑对时，以它们为终点的最长连续公共长度。

那dp数组就出来了，dp[i][j]:以i、j结尾的最长自增子序列。

func findLength(nums1 []int, nums2 []int) int {
	m, n := len(nums1), len(nums2)

	dp := make([][]int, m)
	for i, _ := range dp {
		dp[i] = make([]int, n)
	}

	res := 0

	for j := 0; j < n; j++ {
		if nums2[j] == nums1[0] {
			dp[0][j] = 1
			res = 1
		}
	}
	for i := 1; i < m; i++ {
		if nums1[i] == nums2[0] {
			dp[i][0] = 1
			res = 1
		}
	}

	for i := 1; i < m; i++ {
		for j := 1; j < n; j++ {
			if nums1[i] == nums2[j] {
				dp[i][j] = dp[i-1][j-1] + 1
			}
			if res < dp[i][j] {
				res = dp[i][j]
			}
		}
	}

	return res
}

拓展优化

其实我们看初始化逻辑和递推顺序逻辑是相同的，那么想象一下将整体数组向右下角挪一格。

用 dp[1][1] 来表示 $nums1[0]$ 和 $nums2[0]$ 结尾的情况。

此时如果相等，dp[1][1] = dp[0][0] + 1。

总结来说： dp[i][j] 挪出第一行和第一列留作“无意义的 $0$”，就是为了给第一对元素的比对提供一个安全的“空壳前置位”，让递推公式可以无脑地统一写成 dp[i][j] = dp[i-1][j-1] + 1。

那初始化dp[0][j]和dp[i][0]是0就完全可以了。

此时的dp[i][j]的含义就变了，因为i和j因为多了一行，所以同样位置的数字比如nums[i],现在变成了nums[i-1]

4. 最长公共子序列

题目描述

  1. 给定两个字符串 text1 和 text2，返回这两个字符串的最长公共子序列的长度。

一个字符串的 子序列 是指这样一个新的字符串：它是由原字符串在不改变字符的相对顺序的情况下删除某些字符（也可以不删除任何字符）后组成的新字符串。

例如，“ace” 是 “abcde” 的子序列，但 “aec” 不是 “abcde” 的子序列。两个字符串的「公共子序列」是这两个字符串所共同拥有的子序列。

若这两个字符串没有公共子序列，则返回 0。

示例 1:

输入：text1 = “abcde”, text2 = “ace” 输出：3 解释：最长公共子序列是 “ace”，它的长度为 3。

思路

本题和最长重复子数组是相似的，但是最大的区别就是上一题是连续的，本题是不连续的，这点和最长递增子序列是相同的理念。

同样的思考方式，我们关注结尾，当结尾的nums1[i]和nums2[j]是相同的，那么很好就是dp[i-1][j-1]+1.

那如果不同呢？上一题因为是连续的，所以dp[i][j] = 0.

但本题是不连续的，所以dp[i][j]是需要继承到之前的长度的。

比如text1=‘abc’ text2=‘abe’

当指针指到c和e时，以c、e结尾的最长公共子序列是2，而不是0.

func longestCommonSubsequence(text1 string, text2 string) int {
	m, n := len(text1), len(text2)

	if m == 0 || n == 0 {
		return 0
	}
	dp := make([][]int, m)
	for i, _ := range dp {
		dp[i] = make([]int, n)
	}
	// 第一行
	for j := 0; j < n; j++ {
		if text2[j] == text1[0] {
			for k := j; k < n; k++ {
				dp[0][k] = 1
			}
			break
		}
	}

	// 第一列
	for i := 0; i < m; i++ {
		if text1[i] == text2[0] {
			for k := i; k < m; k++ {
				dp[k][0] = 1
			}
			break
		}
	}

    /*
        上面的初始化，其实更合适的是用继承思想：
        for j := 0; j < n; j++ {
            if text2[j] == text1[0] {
                dp[0][j] = 1
            }else{
                dp[0][j] = dp[0][j-1]
            }
	    }

        for i := 1; i < m; i++ {
            if text1[i] == text2[0]{
                dp[i][0] = 1
            }else{
                 dp[i][0] = dp[i-1][0]
            }
	    }
    */ 

	for i := 1; i < m; i++ {
		for j := 1; j < n; j++ {
			if text1[i] == text2[j] {
				dp[i][j] = dp[i-1][j-1] + 1
			} else {
				dp[i][j] = max(dp[i-1][j], dp[i][j-1])
			}
		}
	}

	return dp[m-1][n-1]
}

func longestCommonSubsequence(text1 string, text2 string) int {
	m, n := len(text1), len(text2)

	dp := make([][]int, m+1)
	for i, _ := range dp {
		dp[i] = make([]int, n+1)
	}

	for i := 1; i < m+1; i++ {
		for j := 1; j < n+1; j++ {

			} else {
				dp[i][j] = max(dp[i-1][j], dp[i][j-1])
			}
		}
	}

	return dp[m][n]
}

5. 不相交的线

题目描述

  1. 在两条独立的水平线上按给定的顺序写下 nums1 和 nums2 中的整数。

现在，可以绘制一些连接两个数字 nums1[i] 和 nums2[j] 的直线，这些直线需要同时满足：

nums1[i] == nums2[j] 且绘制的直线不与任何其他连线（非水平线）相交。 请注意，连线即使在端点也不能相交：每个数字只能属于一条连线。

以这种方法绘制线条，并返回可以绘制的最大连线数。

思路

绘制一些连接两个数字 nums1[i] 和 nums2[j] 的直线，只要 nums1[i] == nums2[j]，且直线不能相交！

直线不能相交，这就是说明在字符串nums1中 找到一个与字符串nums2相同的子序列，且这个子序列不能改变相对顺序，只要相对顺序不改变，连接相同数字的直线就不会相交。

这就是与最长公共子序列是一模一样的

func maxUncrossedLines(nums1 []int, nums2 []int) int {
	m, n := len(nums1), len(nums2)
	dp := make([][]int, m+1)
	for i, _ := range dp {
		dp[i] = make([]int, n+1)
	}

	for i := 1; i < m+1; i++ {
		for j := 1; j < n+1; j++ {
			if nums1[i-1] == nums2[j-1] {
				dp[i][j] = dp[i-1][j-1] + 1
			} else {
				dp[i][j] = max(dp[i-1][j], dp[i][j-1])
			}
		}
	}

	return dp[m][n]
}

6. 最大子序和

题目描述

  1. 给定一个整数数组 nums ，找到一个具有最大和的连续子数组（子数组最少包含一个元素），返回其最大和。

示例:

输入: [-2,1,-3,4,-1,2,1,-5,4] 输出: 6 解释: 连续子数组 [4,-1,2,1] 的和最大，为 6

思路

直觉定义： dp[i] 表示从下标 0 到下标 i 的数组里，最大的连续子序列和。

举个例子： nums = [1, -2, 3]

  • dp[0]（只有 [1]）：最大和是 1。

  • dp[1]（面对 [1, -2]）：最大和还是 1。

  • dp[2]（面对 [1, -2, 3]）：最大和应该是 3（子数组就是 [3]）。

问题来了： 当你在写 dp[2] 的时候，你怎么通过 dp[1]（值是 1）和当前的新数字 3 推导出来 3？ 你推不出来！因为 dp[1] 记录的那个最大和 1，是由子数组 [1] 贡献的，而 [1] 和当前最新的数字 3 在物理上是不连续的（中间隔了一个 -2）。

痛点所在： 直觉的定义丢失了“连续性”。

既然“直觉定义”因为无法保证连续性而失败了，我们就必须在定义里强加一个约束条件，逼着它连续。

这个约束条件就是：最新的这个数字，必须被强行包含进去！

dp[i]:以 nums[i] 为结尾的连续子数组的最大和

我们再用这个定义去走一遍刚才的例子 nums = [1, -2, 3]：

  • dp[0]（必须以 1 结尾）：那就是 [1]，和为 1。

  • dp[1]（必须以 -2 结尾）：我们要么把 -2 接在前面的成果后面（[1, -2]，和为 -1），要么 -2 自己（[-2]，和为 -2）。取大的，所以 dp[1] = -1。

  • dp[2]（必须以 3 结尾）：我们要么把 3 接在前面紧挨着它的成果后面（也就是接在以 -2 结尾的数组后面，和为 dp[1] + 3 = -1 + 3 = 2），要么 3 自己（[3]，和为 3）。取大的，所以 dp[2] = 3。

  1. 确定dp数组

dp[i]:以i结尾的连续子数组的和。

  1. 确定递推公式

dp[i] = max(dp[i-1]+nums[i],nums[i])

  1. dp数组初始化

i 依赖 i-1，

dp[0] = nums[0]

func maxSubArray(nums []int) int {
	n := len(nums)
	dp := make([]int, n)
	dp[0] = nums[0]

	res := dp[0]
	for i := 1; i < n; i++ {
		dp[i] = max(dp[i-1]+nums[i], nums[i])
		if res < dp[i] {
			res = dp[i]
		}
	}
	return res
}

func isSubsequence(s string, t string) bool {
	m, n := len(s), len(t)
	dp := make([][]int, m+1)
	for i, _ := range dp {
		dp[i] = make([]int, n+1)
	}

	for i := 1; i < m+1; i++ {
		for j := 1; j < n+1; j++ {
			if s[i-1] == t[j-1] {
				dp[i][j] = dp[i-1][j-1] + 1
			} else {
				dp[i][j] = dp[i][j-1]
			}
		}
	}

	return dp[m][n] == m
}

func numDistinct(s string, t string) int {

9. 两个字符串的删除操作

题目描述

  1. 给定两个单词 word1 和 word2，找到使得 word1 和 word2 相同所需的最小步数，每步可以删除任意一个字符串中的一个字符。

示例：

输入: “sea”, “eat” 输出: 2 解释: 第一步将"sea"变为"ea”，第二步将"eat"变为"ea"

思路

本题和动态规划不同的子序列相比，其实就是两个字符串都可以删除了，情况虽说复杂一些，但整体思路是不变的。

  1. 确定dp数组

dp[i][j]:以i-1为结尾的字符串word1，和以j-1位结尾的字符串word2，想要达到相等，所需要删除元素的最少次数

  1. 确定递推公式

这一类问题，基本是要分析两种情况

  • 当word1[i - 1] 与 word2[j - 1]相同
    • dp[i][j] = dp[i - 1][j - 1];
  • 当word1[i - 1] 与 word2[j - 1]不相同

    • 情况一：删word1[i - 1]，最少操作次数为dp[i - 1][j] + 1

    • 情况二：删word2[j - 1]，最少操作次数为dp[i][j - 1] + 1

    • 情况三：同时删word1[i - 1]和word2[j - 1]，操作的最少次数为dp[i - 1][j - 1] + 2

    • 因为 dp[i][j - 1] + 1 = dp[i - 1][j - 1] + 2，所以递推公式可简化为：dp[i][j] = min(dp[i - 1][j] + 1, dp[i][j - 1] + 1);

11. 回文子串

题目描述

  1. 给定一个字符串，你的任务是计算这个字符串中有多少个回文子串。

具有不同开始位置或结束位置的子串，即使是由相同的字符组成，也会被视作不同的子串。

示例 1：

  • 输入：“abc”
  • 输出：3
  • 解释：三个回文子串: “a”, “b”, “c”

示例 2：

  • 输入：“aaa”
  • 输出：6
  • 解释：6个回文子串: “a”, “a”, “a”, “aa”, “aa”, “aaa”

思路

如果大家做了很多这种子序列相关的题目，在定义dp数组的时候 很自然就会想题目求什么，我们就如何定义dp数组。

绝大多数题目确实是这样，不过本题如果我们定义，dp[i] 为 下标i结尾的字符串有 dp[i]个回文串的话，我们会发现很难找到递归关系。

dp[i] 和 dp[i-1] ，dp[i + 1] 看上去都没啥关系。

我们在判断字符串S是否是回文，那么如果我们知道 s[1]，s[2]，s[3] 这个子串是回文的，那么只需要比较 s[0]和s[4]这两个元素是否相同，如果相同的话，这个字符串s 就是回文串。

那么此时我们是不是能找到一种递归关系，也就是判断一个子字符串（字符串下标范围[i,j]）是否回文，依赖于，子字符串（下标范围[i + 1, j - 1]）） 是否是回文。

所以为了明确这种递归关系，我们的dp数组是要定义成一位二维dp数组。

布尔类型的dp[i][j]：表示区间范围[i,j] （注意是左闭右闭）的子串是否是回文子串，如果是dp[i][j]为true，否则为false

    • 下标：i 与 j相差大于1的时候，例如cabac，此时s[i]与s[j]已经相同了，我们看i到j区间是不是回文子串

  • s[i]与s[j]不相等

func longestPalindromeSubseq(s string) int {
	n := len(s)
	dp := make([][]int, n)
	for i := range dp {
		dp[i] = make([]int, n)
	}

	for i := 0; i < n; i++ {
		dp[i][i] = 1
	}

	for i := n - 1; i >= 0; i-- {
		for j := i + 1; j < n; j++ {
			if s[i] == s[j] {
				dp[i][j] = dp[i+1][j-1] + 2
			} else {
				dp[i][j] = max(dp[i+1][j], dp[i][j-1])
			}
		}
	}

	return dp[0][n-1]
}

  • 最长递增子序列:
    • $dp[i]$：表示以 $nums[i]$ 为结尾的最长严格递增子序列的长度。
    • 为了比较当前元素与子序列的末尾元素，必须找到每一个子序列。
  • 最长连续递增序列
    • $dp[i]$：表示以 $nums[i]$ 为结尾的最长连续递增子序列的长度。
    • 因为是连续的，所以就找到它紧挨着的元素作为子序列的末尾元素来判断即可。
  • 最长重复子数组
    • $dp[i][j]$：表示以 $A[i-1]$ 和 $B[j-1]$ 为结尾的最长公共连续子数组长度。
    • 涉及两个数组的对比，必然是二维 $dp$。要求“连续”，所以必须强制以当前元素结尾进行严格比对。使用 $i-1$ 是为了简化空数组的边界初始化。
  • 最长公共子序列
    • $dp[i][j]$：表示长度为 $[0, i-1]$ 的字符串 $A$ 与长度为 $[0, j-1]$ 的字符串 $B$ 的最长公共子序列的长度。
    • 非连续问题，不强求以当前字符结尾。它代表的是一个区间内的全局最优解，包含对历史最优状态的继承。
  • 不相交的线
    • 同上，表示 $nums1[0…i-1]$ 和 $nums2[0…j-1]$ 的最大连线数。
    • 连线不相交的本质就是求相对顺序不变的最长公共子序列
  • 最大子序和
    • $dp[i]$：表示以 $nums[i]$ 为结尾的最大连续子序列和。
    • 同理，由于要求“连续子数组”，必须以当前元素作为结尾点，决定是加入前面的连续序列，还是自己另起头。
  • 判断子序列
    • $dp[i][j]$：表示长度为 $i-1$ 的字符串 $s$ 与长度为 $j-1$ 的字符串 $t$ 的最长公共子序列的长度。
    • 本质上是最长公共子序列的降维版应用。只要最终 $dp$ 数组的值等于 $s$ 的长度，即可判定 $s$ 是 $t$ 的子序列。
  • 不同的子序列
    • $dp[i][j]$：表示以 $i-1$ 为结尾的 $s$ 子序列中，出现以 $j-1$ 为结尾的 $t$ 的个数。
    • 匹配类问题。需要用二维数组记录在 $s$ 的不同长度前缀中，能够组合出 $t$ 的前缀的方式总数。
  • 两个字符串的删除操作
    • $dp[i][j]$：表示以 $i-1$ 为结尾的 $word1$ 与以 $j-1$ 为结尾的 $word2$ 达到相等，所需的最少删除次数
    • 也可以通过先求最长公共子序列再做减法来完成，直接定义的话，关注的是操作次数的最优解推导。
  • 编辑距离
    • $dp[i][j]$：表示以下标 $i-1$ 为结尾的字符串 $word1$ ，和以下标 $j-1$ 为结尾的字符串 $word2$，最近编辑距离
    • 理解删除其实就等于添加，而替换相当于一次改的动作
  • 回文子串
    • $dp[i][j]$：表示区间范围 $[i, j]$ 内的子串是否为回文串（布尔值）。
    • 回文串需要判断两头字符是否相等以及中间部分是否为回文，因此需要一个区间范围 $[i, j]$ 来从中心向两端（或从两端向中心）进行状态转移。
  • 最长回文子序列
    • dp[i][j]:字符串s在[i, j]范围内最长的回文子序列的长度为dp[i][j]。

  1. 维度的升降原则 (1D vs 2D)

    • 单序列：当题目只涉及一个数组或字符串（如递增子序列、最大子序和）时，通常使用一维 $dp[i]$ 即可。唯一的例外是“回文串”问题，因为回文的对称性需要两个指针界定区间，所以使用了二维 $dp[i][j]$。

    • 双序列：当题目涉及两个数组或字符串的匹配与计算（如公共子序列、不相交的线、字符串编辑/删除）时，雷打不动使用二维 $dp[i][j]$，用 $i$ 和 $j$ 分别代表两个序列当前的进度。

  2. “连续”与“非连续”的状态绑定

    • 连续型子序列（子串/子数组）：

      -逻辑：$dp$ 数组的状态必须强制与当前元素绑定（即“以 $nums[i]$ 结尾”）。

      • 原因：如果不以此处结尾，下一轮循环就无法判断是否还能继续连在一起。
      • 断层处理：如果当前元素不满足条件，连不上前面的状态，直接将其重置为基准值（如 $0$、$1$ 或当前元素本身）。

    • 非连续型子序列：

      • 逻辑：$dp$ 数组的状态表示该区间范围内的历史最优解，当前元素可以参与，也可以不参与。
      • 断层处理：如果当前元素不匹配，状态不会归零，而是继承历史最优结果（例如二维情况下的 $dp[i][j] = \max(dp[i-1][j], dp[i][j-1])$）。
