## 1. 买卖股票的最佳时机

### 题目描述

给定一个数组 prices ，它的第 i 个元素 prices[i] 表示一支给定股票第 i 天的价格。

你只能选择 某一天 买入这只股票，并选择在 未来的某一个不同的日子 卖出该股票。设计一个算法来计算你所能获取的最大利润。

返回你可以从这笔交易中获取的最大利润。如果你不能获取任何利润，返回 0 。

示例 1：

输入：[7,1,5,3,6,4]

输出：5
解释：在第 2 天（股票价格 = 1）的时候买入，在第 5 天（股票价格 = 6）的时候卖出，最大利润 = 6-1 = 5 。注意利润不能是 7-1 = 6, 因为卖出价格需要大于买入价格；同时，你不能在买入前卖出股票。


### 思路

动态规划的核心是“拆解子问题”。既然要求的是最大利润，最直观的想法是：

让 dp[i] 表示第 $i$ 天能获得的最大利润。

当我们尝试写状态转移方程时，会发现无从下手：

如果第 $i$ 天什么都不做，dp[i] = dp[i-1]。

但如果我想在第 $i$ 天卖出股票来套现呢？我需要知道之前哪天的股票价格最低。然而，我定义的 dp[i-1] 仅仅记录了“最大利润”，把“之前的最低价格”这个关键信息给丢失了。

结论：单一的状态无法同时记录“当前利润”和“我手头有没有股票/之前以多少钱买入”的信息。我们需要对“手头的状态”进行分类讨论。


引入“状态机”思维 —— 拆分状态

思考：

在任何一天，对于这只股票，我们无非处于以下两种最终定格的状态之一：

- 状态 A：我手头正抓着股票。（可能是我今天刚买的，也可能是前几天买了一直没卖）

- 状态 B：我手头没有股票。（可能是我今天刚卖了，也可能是之前就卖了或者从未买过，现在两手空空）

既然有这两种截然不同的处境，且它们会互相转化，那我们就用一个二维数组把它们都记录下来：

dp[i][0]：第 $i$ 天结束后，处于“持有股票”状态时，手里拥有的最多现金。

dp[i][1]：第 $i$ 天结束后，处于“不持有股票”状态时，手里拥有的最多现金。

**总结：动规数组定义的通用套路**
以后遇到类似的题目，你可以这样问自己：

我想求的最终答案是什么？（最大利润）

只记录这个答案，下一天能推导出来吗？如果不能，缺了什么关键信息？（缺了“是否持有股票”的信息）

把缺的信息变成数组的新维度（0 和 1），重新尝试推导。


1. **确定dp数组**

dp[i][0] 表示第i天持有股票所得最多现金 

dp[i][1] 表示第i天不持有股票所得最多现金

2. **确定递推公式**

如果第i天持有股票即dp[i][0]， 那么可以由两个状态推出来

- 第i-1天就持有股票，那么就保持现状，所得现金就是昨天持有股票的所得现金 即：dp[i - 1][0]

- 第i天买入股票，所得现金就是买入今天的股票后所得现金即：-prices[i]

那么dp[i][0]应该选所得现金最大的，所以dp[i][0] = max(dp[i - 1][0], -prices[i]);


> 这里为什么是-prices[i]，而不是dp[i-1][1]-prices[i]？
>
> 因为本题是只买卖一次，如果是dp[i-1][1]-prices[i]，就不能说明仅一次了，dp[i][1]可能是已经卖了的结果了。

如果第i天不持有股票即dp[i][1]， 也可以由两个状态推出来

- 第i-1天就不持有股票，那么就保持现状，所得现金就是昨天不持有股票的所得现金 即：dp[i - 1][1]

- 第i天卖出股票，所得现金就是按照今天股票价格卖出后所得现金即：prices[i] + dp[i - 1][0]

同样dp[i][1]取最大的，dp[i][1] = max(dp[i - 1][1], prices[i] + dp[i - 1][0]);

3.**dp数组初始化**

i是通过i-1得到的，那么dp[0][0]和dp[0][1]是需要的

dp[0][0] = -prices[0]

dp[0][1] = 0


4. **确定遍历顺序**

从前向后

### 代码

```go
func maxProfit(prices []int) int {
	n := len(prices)
	dp := make([][]int, n)
	for i, _ := range dp {
		dp[i] = make([]int, 2)
	}
	// 0是持有 1是不持有
	dp[0][0], dp[0][1] = -prices[0], 0

	for i := 1; i < n; i++ {
		dp[i][0] = max(dp[i-1][0], -prices[i])
		dp[i][1] = max(dp[i-1][1], dp[i-1][0]+prices[i])
	}

	return dp[n-1][1]
}
```


## 2. 买卖股票的最佳时机2

### 题目描述

122. 给定一个数组，它的第 i 个元素是一支给定股票第 i 天的价格。

设计一个算法来计算你所能获取的最大利润。你可以尽可能地完成更多的交易（多次买卖一支股票）。

注意：你不能同时参与多笔交易（你必须在再次购买前出售掉之前的股票）。

### 思路
本题和[买卖股票的最佳时机](#1-买卖股票的最佳时机)的区别在于多次买卖

那在[买卖股票的最佳时机](#1-买卖股票的最佳时机)中也提到了唯一的区别就是dp[i][0] = max(dp[i-1][0], dp[i-1][1]-prices[i])

### 代码

```go
func maxProfit(prices []int) int {
	n := len(prices)
	dp := make([][]int, n)
	for i, _ := range dp {
		dp[i] = make([]int, 2)
	}
	// 0是持有 1是不持有
	dp[0][0], dp[0][1] = -prices[0], 0

	for i := 1; i < n; i++ {
		dp[i][0] = max(dp[i-1][0], dp[i-1][1]-prices[i])
		dp[i][1] = max(dp[i-1][1], dp[i-1][0]+prices[i])
	}

	return dp[n-1][1]
}
```

## 3. 买卖股票的最佳时机3

### 题目描述

123. 给定一个数组，它的第 i 个元素是一支给定的股票在第 i 天的价格。

设计一个算法来计算你所能获取的最大利润。你最多可以完成 两笔 交易。

注意：你不能同时参与多笔交易（你必须在再次购买前出售掉之前的股票）。

### 思路

这个题目与[买卖股票的最佳时机](#1-买卖股票的最佳时机) [买卖股票的最佳时机2](#2-买卖股票的最佳时机2)的不同在于至多买卖两次，这意味着可以买卖一次，可以买卖两次，也可以不买卖。

回顾[买卖股票的最佳时机](#1-买卖股票的最佳时机)的dp数组的思考过程，

**当一个维度（天数）和状态（是否持有）无法完整表达约束时，就必须拆分状态，或者引入新的维度（交易次数。**，从而有了dp[i][0]和dp[i][1]两个维度。

那回到本题。沿用[买卖股票的最佳时机](#1-买卖股票的最佳时机)的定义，就会发生严重的状态模糊：
- 如果第 $i$ 天结束，你手里持有股票（dp[i][0]），这究竟是你的第一次买入，还是第二次买入？（如果是第二次买入，你之前必须已经有过一次买卖，手里的初始资金是第一次赚到的钱，而不是 $0$）。
  
- 如果第 $i$ 天结束，你手里不持有股票（dp[i][1]），这究竟是你第一次卖出了，还是第二次卖出彻底清仓了？

结论： 仅仅用“持有/不持有”这两个状态，已经无法区分我们到底在进行第几次交易了

为了解决这种“模糊”，我们需要把交易次数融入到状态中。有两种思考方向，最终殊途同归：

- 思考方向 A：直接拆分状态
  - 既然只有两次交易，那么“持有”和“不持有”各会被使用两次。加上一个初始的“不操作”，一天一共就定格在以下 $5$ 种具体的状态 之一：
  - dp[i][0]：没有操作（一直空仓）。
  - dp[i][1]：第一次持有股票。
  - dp[i][2]：第一次不持有股票（即第一次卖出套现后）。
  - dp[i][3]：第二次持有股票（在第一次卖出挣到钱的基础上，再次买入）。
  - dp[i][4]：第二次不持有股票（第二次卖出套现后）。

- 思考方向 B：增加一个“交易次数”的维度
  - 如果不去硬生生拆成 0-4，我们可以直接在 121 题的二维数组上，追加第三个维度 k（表示这是第几次交易）：定义 dp[i][j][k]：第 $i$ 天，状态为 $j$（0持有，1不持有），这是第 $k$ 次交易（$k=1$ 或 $2$）。
  - 当把这个三维数组展开时：
  - dp[i][0][1] $\rightarrow$ 对应 dp[i][1]（第一次持有）
  - dp[i][1][1] $\rightarrow$ 对应 dp[i][2]（第一次不持有）
  - dp[i][0][2] $\rightarrow$ 对应 dp[i][3]（第二次持有）
  - dp[i][1][2] $\rightarrow$ 对应 dp[i][4]（第二次不持有）

1. **确定dp数组**

本文首先使用思路A：

- dp[i][0]:没有操作，也不可以不定义这个状态

- dp[i][1]:第一次持有股票，所剩最大现金

- dp[i][2]:第一次不持有股票，所剩最大现金

- dp[i][3]:第二次持有股票，所剩最大现金

- dp[i][4]:第二次不持有股票，所剩最大现金


2.**确定递推公式**

- dp[i][1] = max(dp[i-1][0]-prices[i],dp[i-1][1])

- dp[i][2] = max(dp[i-1][1]+prices[i],dp[i-1][2])

- dp[i][3] = max(dp[i-1][2]-prices[i],dp[i-1][3])

- dp[i][4] = max(dp[i-1][3]+prices[i],dp[i-1][4])

3.**dp数组初始化**

根据公式可以看出dp[i]是依赖于dp[i-1]的

dp[0][0] = 0

dp[0][1] = -prices[0] 

dp[0][2] = 0

dp[0][3] = -prices[0]

dp[0][4] = 0


4.**确定遍历顺序**

从左到右

### 代码

```go
func maxProfit(prices []int) int {
	n := len(prices)
	dp := make([][]int, n)
	for i, _ := range dp {
		dp[i] = make([]int, 5)
	}

	dp[0][0] = 0

	dp[0][1] = -prices[0]

	dp[0][2] = 0

	dp[0][3] = -prices[0]

	dp[0][4] = 0

	for i := 1; i < n; i++ {
		dp[i][1] = max(dp[i-1][0]-prices[i], dp[i-1][1])

		dp[i][2] = max(dp[i-1][1]+prices[i], dp[i-1][2])

		dp[i][3] = max(dp[i-1][2]-prices[i], dp[i-1][3])

		dp[i][4] = max(dp[i-1][3]+prices[i], dp[i-1][4])
	}

	// return max(dp[n-1][4], dp[n-1][2], dp[n-1][0])
    return dp[n-1][4]
}
```

> 最后的return可以直接写dp[n-1][4]。
> 
> 因为根据公式
> 
> `dp[i][3] = max(dp[i-1][2]-prices[i],dp[i-1][3])`
>
>`dp[i][4] = max(dp[i-1][3]+prices[i],dp[i-1][4])`
>
>可以看出，如果每次迭代都是有新的最大值，那么
>
>dp[i][4] = dp[i-1][3]+prices[i] = dp[i-1][2]-prices[i]  + prices[i]  = dp[i-1][2]
>
>dp[i][4]一定是大于等于dp[i][2]的
>
>同理，dp[i][2]一定是大于等于dp[i][0]的

### 拓展

对于思考方向B的代码如下，整体的思路其实是一样的。

```go
func maxProfit(prices []int) int {
	n := len(prices)
	dp := make([][][]int, n)
	for i, _ := range dp {
		dp[i] = make([][]int, 2) // 0持有或者1不持有
		for j, _ := range dp[i] {
			dp[i][j] = make([]int, 3) // 1第一次持有  2 第二次持有
		}
	}

	dp[0][0][1] = -prices[0]

	dp[0][1][1] = 0

	dp[0][0][2] = -prices[0]

	dp[0][1][2] = 0

	for i := 1; i < n; i++ {
		// 第一次持有
		dp[i][0][1] = max(-prices[i], dp[i-1][0][1])
		// 第一次不持有
		dp[i][1][1] = max(dp[i-1][0][1]+prices[i], dp[i-1][1][1])
		// 第二次持有
		dp[i][0][2] = max(dp[i-1][1][1]-prices[i], dp[i-1][0][2])
		// 第二次不持有
		dp[i][1][2] = max(dp[i-1][0][2]+prices[i], dp[i-1][1][2])
	}

	return dp[n-1][1][2]
}
```


## 4. 买卖股票的最佳时机4

### 题目描述
188. 给定一个整数数组 prices ，它的第 i 个元素 prices[i] 是一支给定的股票在第 i 天的价格。

设计一个算法来计算你所能获取的最大利润。你最多可以完成 k 笔交易。

注意：你不能同时参与多笔交易（你必须在再次购买前出售掉之前的股票）。


### 思路

这个题目和[买卖股票的最佳时机3](#3-买卖股票的最佳时机3)是极为相似的，不同点就是在于k次交易。

那沿用[买卖股票的最佳时机3](#3-买卖股票的最佳时机3)的思路，就是

- dp[i][0]:没有操作

- dp[i][1]:第一次持有股票，所剩最大现金

- dp[i][2]:第一次不持有股票，所剩最大现金

- dp[i][3]:第二次持有股票，所剩最大现金

- dp[i][4]:第二次不持有股票，所剩最大现金

- dp[i][5]:第三次持有股票，所剩最大现金

- dp[i][6]:第四次不持有股票，所剩最大现金 

- ...

这时候就发现规律了，除了0以外，偶数就是卖出，奇数就是买入。

题目要求是至多有K笔交易，那么j的范围就定义为 2 * k + 1 就可以了


1. **确定dp数组**

本文首先使用思路A：

- dp[i][0]:没有操作，也不可以不定义这个状态

- dp[i][1]:第一次持有股票，所剩最大现金

- dp[i][2]:第一次不持有股票，所剩最大现金

- dp[i][3]:第二次持有股票，所剩最大现金

- dp[i][4]:第二次不持有股票，所剩最大现金

- ...


2.**确定递推公式**

- dp[i][1] = max(dp[i-1][0]-prices[i],dp[i-1][1])

- dp[i][2] = max(dp[i-1][1]+prices[i],dp[i-1][2])

- dp[i][3] = max(dp[i-1][2]-prices[i],dp[i-1][3])

- dp[i][4] = max(dp[i-1][3]+prices[i],dp[i-1][4])

- ...

- dp[i][j] = max(dp[i-1][j-1]-prices[i], dp[i-1][j])
  
- dp[i][j+1] = max(dp[i-1][j]+prices[i], dp[i-1][j+1])

3.**dp数组初始化**

根据公式可以看出dp[i]是依赖于dp[i-1]的

dp[0][0] = 0

dp[0][1] = -prices[0] 

dp[0][2] = 0

dp[0][3] = -prices[0]

dp[0][4] = 0


dp[0][j] = -prices[0]


4.**确定遍历顺序**

从左到右


## 代码

```go
func maxProfit(k int, prices []int) int {
	n := len(prices)
	dp := make([][]int, n)
	for i, _ := range dp {
		dp[i] = make([]int, 2*k+1)
	}

	// 只有奇数位置是-prices[0]
	for i := 1; i <= 2*k; i += 2 {
		dp[0][i] = -prices[0]
	}

	for i := 1; i < n; i++ {
		for j := 1; j < 2*k+1; j += 2 {
			dp[i][j] = max(dp[i-1][j-1]-prices[i], dp[i-1][j])
			dp[i][j+1] = max(dp[i-1][j]+prices[i], dp[i-1][j+1])
		}
	}

	return dp[n-1][2*k]
}
```


## 5. 最佳买卖股票时机含冷冻期

### 题目描述

给定一个整数数组，其中第 i 个元素代表了第 i 天的股票价格 。

设计一个算法计算出最大利润。在满足以下约束条件下，你可以尽可能地完成更多的交易（多次买卖一支股票）:

你不能同时参与多笔交易（你必须在再次购买前出售掉之前的股票）。
卖出股票后，你无法在第二天买入股票 (即冷冻期为 1 天)。

### 思路

其实这个题目是加一个状态，就是冷冻期

那第一想法：

- dp[i][0]:持有
- dp[i][1]:不持有
- dp[i][2]:冷冻期

但是当推导dp[i][2]时，是需要知道前一天是卖出的具体操作的那一天的，所以dp[i][1]的不持有就需要拆成两个状态

- dp[i][0]:持有
- dp[i][1]:不持有的保持状态
- dp[i][2]:具体在这一天卖出去
- dp[i][3]:冷冻期

1. **确定dp数组**

- dp[i][0]:持有
- dp[i][1]:不持有的保持状态
- dp[i][2]:具体在这一天卖出去
- dp[i][3]:冷冻期


2.**确定递推公式**

- dp[i][0] = max(dp[i-1][0], dp[i-1][1]-prices[i],dp[i-1][3]-prices[i]) 
  - 前一天就持有了
  - 前一天是保持不持有的状态，然后今天买入了
  - 前一天是冷静期，然后今天买入了
  
- dp[i][1] = max(dp[i-1][1],dp[i-1][3])
  - 前一天就不持有
  - 前一天是冷静期

- dp[i][2] = dp[i-1][0]  + prices[i]
  - 前一天一定持有

- dp[i][3] = dp[i-1][2]
  - 前一天一定卖出

3.**dp数组初始化**

根据公式可以看出dp[i]是依赖于dp[i-1]的

dp[0][0] = -prices[0]

dp[0][1] = 0

dp[0][2] = 0

dp[0][3] = 0


4.**确定遍历顺序**

从左到右

### 代码

```go
func maxProfit(prices []int) int {
	n := len(prices)
	dp := make([][]int, n)
	for i, _ := range dp {
		dp[i] = make([]int, 4)
	}
	dp[0][0] = -prices[0]

	dp[0][1] = 0

	dp[0][2] = 0

	dp[0][3] = 0

	for i := 1; i < n; i++ {
		dp[i][0] = max(dp[i-1][0], dp[i-1][1]-prices[i], dp[i-1][3]-prices[i])

		dp[i][1] = max(dp[i-1][1], dp[i-1][3])

		dp[i][2] = dp[i-1][0] + prices[i]

		dp[i][3] = dp[i-1][2]
	}
	return max(dp[n-1][1], dp[n-1][2], dp[n-1][3])
}
```


## 6. 买卖股票的最佳时机含手续费

### 题目描述

714. 给定一个整数数组 prices，其中第 i 个元素代表了第 i 天的股票价格 ；非负整数 fee 代表了交易股票的手续费用。

你可以无限次地完成交易，但是你每笔交易都需要付手续费。如果你已经购买了一个股票，在卖出它之前你就不能再继续购买股票了。

返回获得利润的最大值。

注意：这里的一笔交易指买入持有并卖出股票的整个过程，每笔交易你只需要为支付一次手续费。

### 思路

这个题目几乎和[买卖股票的最佳时机2](#2-买卖股票的最佳时机2)一模一样，只是多了一个手续费。

```go
func maxProfit(prices []int, fee int) int {
	n := len(prices)
	dp := make([][]int, n)
	for i, _ := range dp {
		dp[i] = make([]int, 2)
	}

	dp[0][0] = -prices[0]
	dp[0][1] = 0

	for i := 1; i < n; i++ {
		dp[i][0] = max(dp[i-1][0], dp[i-1][1]-prices[i])
		dp[i][1] = max(dp[i-1][1], dp[i-1][0]+prices[i]-fee)
	}
	return dp[n-1][1]
}
```

## 总结

关于买卖股票的问题，其实就是计算每一天能买卖股票的最大利润。但是买或者卖，是取决于手中股票的状态，也就是你手头到底有没有股票，因为不允许同时持股，所以需要单独一个**维度**来描述这个状态

所以这些题目中就衍生出了几个状态：

- [](#1-买卖股票的最佳时机):持有、不持有
- [](#2-买卖股票的最佳时机2):持有、不持有
- [](#3-买卖股票的最佳时机3):第一天持有、第一天不持有、第二天持有、第二天不持有
- [](#4-买卖股票的最佳时机4):第一天持有、第一天不持有、第二天持有、第二天不持有、...
- [](#5-最佳买卖股票时机含冷冻期):持有、保持不持有、具体卖出、冷静期
- [](#6-买卖股票的最佳时机含手续费):持有、不持有

其中第三、四题是又拆成了具体的天数，因为后边的天数比如第二天，是需要知道第一次不持有状态的，所以需要拆开。

其中第五题是将不持有状态拆分成的保持不持有或具体卖出两个状态，因为冷静期是需要知道具体卖出状态的，所以需要单独拆出来。
