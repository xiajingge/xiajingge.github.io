完全背包和01背包问题唯一不同的地方就是，每种物品有**无限件**。

在读本文之前，需要先看[01背包](./动态规划：01背包理论基础.md)的理论原理，这样才能更好的读取完全背包。

还是同样的例子。

假设现在有这样的一个问题：有一个重量容量为4的背包，可以装以下的物品，问背包能背的物品的最大价值是多少？

|       | 重量  | 价值  |
| :---: | :---: | :---: |
| 物品0 |   1   |  15   |
| 物品1 |   3   |  20   |
| 物品2 |   4   |  30   |

但是增加一个条件，就是每一件物品是无限个数。

## 二维dp方案

那现在同样先给出一个dp二维数组，主要是两个维度：物品和背包重量

![dp数组样式](/posts/images/01背包dp初始化.svg)


可以看出二维输出的行是物品种类，列是背包容量。

那先来填一下这个数组的内容。


- 先看第一行：

  在仅考虑物品0的情况下：

![dp数组第一行](/posts/images/完全背包第一行.svg)

- 再看第二行

![dp数组第二行](/posts/images/完全背包第二行.svg)

那就是我们要推出dp[i][j],这里我们拿dp[1][4]举例。

求dp[1][4]就是两种情况：
- **不放物品1** 

    那先看不放物品1的情况，那就是只放物品0。就是dp[0][4]的值

    ![dp数组第二行](/posts/images/完全背包第二行推导1.svg)

- **放物品1**

    那么背包要先留出物品1的容量，目前容量是4，物品1 的容量（就是物品1的重量）为3，此时背包剩下容量为1
    容量为1，只考虑放物品0 和物品1 的最大价值是 dp[1][1]，注意，这里和[01背包理论]((./动态规划：01背包理论基础.md))就不同了。

    在 [01背包理论]((./动态规划：01背包理论基础.md))中，背包先空留出物品1的容量，此时容量为1，只考虑放物品0的最大价值是 dp[0][1]，因为01背包每个物品只有一个，既然空出物品1，那背包中也不会再有物品1！

    而在完全背包中，物品是可以放无限个，所以 即使空出物品1空间重量，那背包中也可能还有物品1，所以此时我们依然考虑放 物品0 和 物品1 的最大价值即： dp[1][1]， 而不是 dp[0][1]

    ![dp数组第二行](/posts/images/完全背包第二行推导2.svg)


以上过程，抽象化如下：

不放物品i：背包容量为j，里面不放物品i的最大价值是dp[i - 1][j]。

放物品i：背包空出物品i的容量后，背包容量为j - weight[i]，dp[i][j - weight[i]] 为背包容量为j - weight[i]且不放物品i的最大价值，那么dp[i][j - weight[i]] + value[i] （物品i的价值），就是背包放物品i得到的最大价值

递归公式： dp[i][j] = max(dp[i - 1][j], dp[i][j - weight[i]] + value[i]);

> （注意，完全背包二维dp数组 和 01背包二维dp数组 递推公式的区别，01背包中是 dp[i - 1][j - weight[i]] + value[i])）


关于初始化，根据递推公式可以看出，第一行和第一列肯定是需要初始化的。

第一列好讲，容量为0，可能是什么物品都放不了，就是0
第一行呢，就是当容量大于物品重量时，就一直放。

```go
for  i := 0;i < len(weight);i++{
    dp[i][0] = 0
}

for j := 0;j <= bagsize; j++{
    if j < weight[0]{
        dp[0][j] = 0
    }else{
        dp[0][j] = dp[0][j-weight[0]] + value[0]
    }

}
```

dp[0][j] 和 dp[i][0] 都已经初始化了，那么其他下标应该初始化多少呢？

其实从递归公式： dp[i][j] = max(dp[i - 1][j], dp[i][j - weight[i]] + value[i]); 可以看出dp[i][j] 是由上方和左方数值推导出来了，那么 其他下标初始为什么数值都可以，因为都会被覆盖。

但只不过一开始就统一把dp数组统一初始为0，更方便一些。

这样的情况下，其实第一列就不需要声明初始化。

```go
dp := make([][]int,len(weight))

for i,_ := range dp{
    dp[i] = make([]int,bagsize + 1)
}

for j := weight[0];j <= bagsize; j++{
    dp[0][j] = dp[0][j-weight[0]] + value[0]
}
```


[01背包理论]((./动态规划：01背包理论基础.md))中我们讲过，01背包二维DP数组，先遍历物品还是先遍历背包都是可以的。

因为两种遍历顺序，对于二维dp数组来说，递推公式所需要的值，二维dp数组里对应的位置都有。

```go
// 先遍历物品，再遍历背包容量
for i := 1;i< len(weight);i++{
    for j := 0;j <= bagsize;j++{
        if j < weight[i]{
            dp[i][j] = dp[i-1][j]
        }else{
            dp[i][j]=max(dp[i-1][j],dp[i][j-weight[i]]+value[i])
        }
    }
}
// 先遍历背包容量，再遍历物品
for j := 0;j <= bagsize;j++{
    for i := 1;i< len(weight);i++{
        if j < weight[i]{
            dp[i][j] = dp[i-1][j]
        }else{
            dp[i][j]=max(dp[i-1][j],dp[i][j-weight[i]]+value[i])
        }
    }
}
```


那完成的代码如下：
```go
package main

import (
    "fmt"
)

func main(){
    var n,bagsize int // 声明物品种类数量和背包容量
    fmt.Scan(&n,&bagsize)

    weight := make([]int,n) //存储每个物品的重量
    value := make([]int,n) //存储每个物品的价值

    for i := 0;i<n;i++{
        fmt.Scan(&weight[i])
    }
    
    for j := 0;j<n;j++{
        fmt.Scan(&value[j])
    }

    // 完全背包
    dp := make([][]int,len(weight))

    for i,_ := range dp{
        dp[i] = make([]int,bagsize + 1)
    }

    for j := weight[0];j <= bagsize; j++{
        dp[0][j] = dp[0][j-weight[0]] + value[0]
    }

    // 遍历
    for i := 1;i< len(weight);i++{
        for j := 0;j <= bagsize;j++{
            if j < weight[i]{
                dp[i][j] = dp[i-1][j]
            }else{
                dp[i][j]=max(dp[i-1][j],dp[i][j-weight[i]]+value[i])
            }
        }
    }

    // 返回最终结果
	fmt.Println(dp[n-1][bagsize])
}
```

## 一维dp方案

```go
for i := 0; i < n; i++ {               // 遍历物品
    for j := weight[i]; j <= bagsize; j++ {   // 正序遍历容量
        dp[j] = max(dp[j], dp[j-weight[i]] + value[i])
    }
}
```

```go
package main

import "fmt"

func max(a, b int) int {
    if a > b {
        return a
    }
    return b
}

func main() {
    var n, bagsize int
    fmt.Scan(&n, &bagsize)

    weight := make([]int, n)
    value := make([]int, n)

    for i := 0; i < n; i++ {
        fmt.Scan(&weight[i])
    }
    for i := 0; i < n; i++ {
        fmt.Scan(&value[i])
    }

    dp := make([]int, bagsize+1)

    for i := 0; i < n; i++ {
        for j := weight[i]; j <= bagsize; j++ {  // 正序
            dp[j] = max(dp[j], dp[j-weight[i]]+value[i])
        }
    }

    fmt.Println(dp[bagsize])
}
```
